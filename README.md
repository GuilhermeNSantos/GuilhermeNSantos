## 👨‍💻 About Me

Sou **Guilherme Nascimento Santos**, estudante de **Sistemas de Informação** na **Universidade Federal de Uberlândia (UFU)**.

Meu objetivo é me tornar **Full Stack Developer com Python no back-end** e **JavaScript no front-end**, criando aplicações completas, bem organizadas e escaláveis, da API até a interface.

- 🐍 Apaixonado por **Python**, lógica e resolução de problemas
- 🌐 Construindo interfaces modernas com **Next.js, TypeScript e Tailwind**
- ⚡ Desenvolvendo APIs com **FastAPI** e **Django**
- 🇺🇸 Estudando inglês todos os dias para uma carreira internacional
- 📈 Foco em evolução constante: cada projeto é um degrau

> *"Constantly building projects, practicing logic, and refining software development skills."*

## 🧠 Engineering Mindset

- **Build for maintainability**: código legível, responsabilidades claras e design pragmático.
- **Protect data and systems**: modelagem relacional, validação, segurança e testes.
- **Think end to end**: entender como o software vai do desenvolvimento ao deploy e à operação.
